Backup & restore

Your data is saved automatically on this computer, in this browser. It's still wise to download a backup file now and then — especially before clearing browser data or moving to a new computer.

Automatic daily backups

Khata quietly saves a snapshot the first time it's opened each day, kept for the last 14 days — a safety net for a bad edit or accidental deletion. Not a substitute for the "Download backup file" button above, which you should still use before anything risky.

Import from Tally (XML)

Upload a Tally XML export (e.g. a Day Book export containing Sales/Purchase vouchers). Nothing is saved right away — every voucher is shown for review first, with each party and product checked against what's already in Khata: matched automatically where the name is identical, or left for you to choose "Add as new" vs "Match to existing" wherever it isn't. Only once you press "Confirm & Import" does anything actually post, into whichever company is currently active — switch to a test company first if you want to try this safely. HSN and GST% aren't in Tally's voucher data, so newly created products are left blank there for you to fill in afterward.

Export to Tally (XML)

Writes Sale, Purchase, Receipt, Payment, Expense, Income, Contra, and Journal vouchers in a chosen date range into a Tally-importable XML file. Sale/Purchase Returns export as Tally Credit/Debit Notes, since Tally doesn't have a "Return" voucher type of its own. Party and product names need to already exist in Tally (or match exactly) for its own import to accept them — this only writes the file, it doesn't touch Tally itself.

Bank Reconciliation

Upload your bank statement (CSV). Each line shows up for you to Confirm, Record in Khata (if it's something not yet entered — a bank charge, interest, etc.), or Flag for later scrutiny. Once every line here is Confirmed or Flagged, set a new checkpoint — next time, only lines after that date show up.
